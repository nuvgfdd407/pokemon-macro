ストーリーマクロ

ボタンは1つだけ

ボードの「BOOT」と書かれたボタンを使います（「RESET」は押さない）。押し方は3つだけです。

ちょん押し次の機能に変える
1秒長押しスタート ／ ストップ
素早く2回押し「剣盾」と「BDSP」を切り替える

使う流れ

  1. ゲームの中で準備する下の説明にある「スタート前にやること」と「手動の準備」を、いつものコントローラーでやっておく。
  2. ボードをSwitchに挿す先に「コントローラー」→「持ちかた/順番を変える」を開いてから、ドックのUSBに挿す。LEDがオレンジに光って自動で登録される。点滅に変わったら完了。画面を閉じてゲームに戻る。
  3. 素早く2回押しで作品を選ぶ剣盾 ⇔ BDSP が切り替わる。切り替えると作品の色で3回速く光る（剣盾＝オレンジ、BDSP＝青緑）。
  4. ちょん押しで機能を選ぶLEDが「色」と「点滅の回数」で今の機能を教えてくれる。下の一覧と見比べて、使いたい機能になるまでちょん押しする。
  5. 1秒長押しでスタート数を聞く機能は、LEDが水色になる。下の「回数の入れ方」のとおりに押す。LEDが作品の色で光りっぱなしになったら動いている。
  6. 途中で止めるときも1秒長押し

機能の一覧

止まっているあいだ、LEDは作品の色で点の数だけ点滅をくり返します。たとえば は「オレンジが2回ずつ点滅」＝ 剣盾の中盤以降。

「手動の準備」はボードの機能ではなく、自分でやる作業（剣盾／BDSP）。

回数の入れ方

スタートすると、機能によってはLEDが水色になって数を聞いてきます。

  • 水色のあいだ（4秒）に押した回数が、その数になる。押すたびに白く光る。
  • 何も押さなければ 0（この説明書では「押さない」と書く）。
  • 水色が一度消えて、また水色になったら次の質問。
例：「始めるパート番号」を 12 にしたいとき（質問が2回くる）
1回目の水色 → 1回押す（10の位）
2回目の水色 → 2回押す（1の位）
5番なら、1回目は押さずに待って、2回目に5回押す。どちらも押さなければ最初から。

機能ごとの説明（剣盾）

おおまかな流れ

  1. 序盤（約45分）名前を決めた直後 → 最初のワイルドエリア。イワークにやられてエンジンシティ前に戻り、本体がスリープして終わる。
  2. 手動の準備（30分くらい）シェルダーを捕まえて育てる。自爆用とダブルバトル用のポケモンも用意する。
  3. 中盤以降 設定（一度だけ）DLCの有無・背番号・ムゲンダイナのボールを決める。
  4. 中盤以降（約6時間）エンジンシティの入り口 → 殿堂入り。最後に本体がスリープして終わる。
  5. クリア後（使いたいときだけ）ザシアン・ザマゼンタ（約1時間）、バドレックス（約3時間）。どちらも捕獲の直前まで。

ゲーム内の設定（話の速さなど）は、序盤の中で自動で変える。

Switch 2 ではまだ試していない（初代Switch向けに作られたもの）。

手動の準備（序盤と中盤以降の間）

自分のコントローラーでやる。30分くらい。

  1. シェルダーを捕まえるエンジンシティ前に戻った場所から、正面の湖の釣りポイントで釣りをする（シェルダーは20%）。特性がスキルリンクで、性格が攻撃の下がるものでないかを確認する（性格はあとでミントでもOK）。
  2. 育成用のデータに送るポケモンHOMEで、育成用の別のセーブデータに送る。経験アメ、銀の王冠、タウリン・インドメタシン（各26個）などが要るので、育成用のデータはクリア済みのものがおすすめ。
  3. シェルダーを育てるLv100、努力値は攻撃・素早さ252、攻撃に銀の王冠。素早さが下がる性格で個体値15以下なら素早さにも王冠（パルシェンの素早さが201以上になるように）。技はつららばりだけにする。
  4. 自爆用のポケモンを用意する自爆を覚える低レベルのポケモン（タンドンなど）。技の一番上を「じばく」にする。
  5. ダブルバトル用のポケモンを用意するLv80以下で、この先レベルアップで技を覚えないポケモン。技の一番上を相手2体を攻撃する技にする（ワイルドエリアのLv60くらいのオノノクス＋ワイドブレイカーがおすすめ）。
  6. 元のデータに戻すもう一度ポケモンHOMEで、自動で進めるセーブデータに戻す。
  7. 手持ちとボックスを並べる手持ちはシェルダー1匹だけ。ボックス1の左上に自爆用、左下にダブルバトル用を置く。

機能ごとの説明（BDSP）

おおまかな流れ

  1. 序盤（約2時間）名前を決めた直後 → コトブキシティで「ふしぎなおくりもの」解放まで。最初のポケモンはヒコザル。

  3. 中盤204番道路の看板の前 → ポケモンリーグ到達。そのあと図鑑埋めの寄り道とサファリゲーム。
  4. 手動ライバル・四天王・チャンピオンは自分で戦う。

Switch 2 ではまだ試していない（初代Switch向けに作られたもの）。Switch 2 では読み込みの速さの違いで歩数がずれるという報告がある。

自分のコントローラーでやる。

  1. ポケモンを1匹捕まえる草むらで捕まえる（通信交換に2匹以上必要）。
  2. ヒコザルを育てる通信交換で別のデータに送り、Lv68以上のゴウカザル（フレアドライブを覚えるところまで）に育てる。性格が攻撃の下がるもの（ひかえめなど）でなければOK。
  3. 技と持ち物技を上から「かえんほうしゃ」「マッハパンチ」「アクロバット」「インファイト」にする（ノモセシティでハートのウロコで思い出せる）。持ち物は持たせない。
  4. 手持ちとボックスゴウカザルを戻し、手持ちをゴウカザル1匹だけにする。ボックス1の左上に適当なポケモンを預けて（やりのはしらのダブルバトル用。上の技がまともな攻撃技だと安心）、ボックスを閉じる。
  5. 道具を買って並べるショップで「むしよけスプレー」20個以上、「あなぬけのヒモ」3個以上を買い、道具ポケットの一番上を むしよけ → あなぬけ の順に並べる（お気に入りは全部外す）。余計な道具は買わない。
  6. メニューの並びXボタンのメニューで、上の段の一番左の「図鑑」と左から3番目の「バッグ」を入れ替え、[バッグ][ポケモン][図鑑]… の順にする。
  7. 本体の時刻18時〜1時にしておく（朝だけ出るトレーナーを避けるため）。
  8. 204番道路のトレーナー看板の左と下にいる短パン小僧・ミニスカートは倒しておく（序盤で倒している）。
