色違いマクロ

ボタンは1つだけ

ボードの「BOOT」と書かれたボタンを使います（「RESET」は押さない）。押し方は3つだけです。

ちょん押し次の機能に変える
1秒長押しスタート ／ ストップ
素早く2回押し作品を変える（剣盾 → BDSP → FRLG → 剣盾…）

使う流れ

  1. ゲームの中で準備する下の機能の説明にある「スタート前にやること」と「スタート位置」を、いつものコントローラーでやっておく。
  2. ボードをSwitchに挿す先に「コントローラー」→「持ちかた/順番を変える」を開いてから、ドックのUSBに挿す。LEDがピンクに光って自動で登録される（青く光るのは剣盾多機能のボード）。点滅に変わったら登録完了。画面を閉じてゲームに戻る。
  3. 素早く2回押しで作品を選ぶ剣盾 → BDSP → FRLG → 剣盾…の順に変わる。変えると作品の色で3回速く光る（剣盾＝ピンク、BDSP＝青緑、FRLG＝赤）。
  4. ちょん押しで機能を選ぶLEDが「色」と「点滅の回数」で今の機能を教えてくれる。下の一覧と見比べて、使いたい機能になるまでちょん押しする。
  5. 1秒長押しでスタート数を聞く機能は、LEDが水色になる。下の「回数の入れ方」のとおりに押す。LEDが作品の色で光りっぱなしになったら動いている。
  6. 止めるときも1秒長押し色違いが出て止まっているときも、まず1秒長押しして止めてから、自分で捕まえる。

抜いても、選んでいた機能・レジの対象・タイミング調整は覚えている。

機能の一覧

止まっているあいだ、LEDは作品の色で点の数だけ点滅をくり返します。たとえば は「青緑が2回ずつ点滅」＝ ダークライ。

剣盾 色違い（LEDはピンク）
レジ系 無人厳選 強いシンボル 無人厳選 タイミング調整
BDSP 色違い（素早く2回押しで切り替え。LEDは青緑）
シェイミ 無人厳選 ダークライ 無人厳選 アルセウス 無人厳選 タイミング調整（BDSP）
FRLG 色違い（もう一度素早く2回押し。LEDは赤）
野生（あまいかおり） サンダー フリーザー ファイヤー デオキシス

回数の入れ方

スタートすると、機能によってはLEDが水色になって数を聞いてきます。

  • 水色のあいだ（4秒）に押した回数が、その数になる。押すたびに白く光る。
  • 何も押さなければ 0。
  • 水色が一度消えて、また水色になったら次の質問。
例：サンダーで、ゴールドスプレーを 150本 持っているとき（質問が4回くる）
1回目の水色 → 押さない（スプレーの種類＝ゴールド）
2回目の水色 → 1回押す（100の位）
3回目の水色 → 5回押す（10の位）
4回目の水色 → 押さない（1の位）

最初に1回だけやっておくこと

  • 剣盾・BDSPは、最初に必ずタイミング調整をする（剣盾 ／ BDSP）。FRLGは待ち時間をSwitch 2に合わせてあるので調整しなくていい

剣盾

  • ゲームのオプション：話の速さ「はやい」／ちょいらく「しない」
  • 本体の設定：「インターネットで時刻を合わせる」をオフ
  • 手持ちの先頭：色違いでない／登場時に発動する特性でない／逃げられる（素早い、または「けむりだま」を持たせる）／なつき度が高くない
  • 連れ歩き：オフ（フリーズ村の男の子に話しかける）

BDSP

  • ゲームのオプション：話の速さ「はやい」／戦闘アニメ「みない」
  • 手持ちの先頭：いちばん上の技を、自分が倒れる技にする（「いやしのねがい」がおすすめ。「おきみやげ」などでもいい）
  • 手持ちの先頭：足が遅ければ「けむりだま」を持たせる／なつき度を下げておく
  • 捕まえるためのポケモンとボールを用意しておく

FRLG

  • ゲームの「せってい」：せんとうアニメ「みない」／話のはやさ「はやい」／ボタンモード「LR」（「かたて」にしない）
  • 手持ちの先頭：相手より確実に速い／登場時に発動する特性でない（「いかく」「プレッシャー」などはだめ）

機能ごとの説明：剣盾 色違い

しくみ

色違いが出ると、光る演出のぶん戦闘メニューが約2秒遅れて出る。マクロは決まった時間に「にげる」を入力するので、

  • ふつうのポケモン → 逃げて、次へ進む
  • 色違い → メニューが間に合わず、手持ちのポケモンの画面に入って止まる

ゲームが止まっていたら、1秒長押しでマクロを止めて、自分で戻って捕まえる。

最初に必ずタイミング調整をする。「にげる」を入力する瞬間にLEDが白く光る。ふつうのポケモンが出たとき、戦闘メニューが出てから0.5〜1.5秒後に白く光るように合わせる。

レジ系 無人厳選

部屋の隅から光のパズルを解いて像に話しかけ、戦闘 →「にげる」をくり返す。20回ごとに建物を出て、光をリセットする。

スタート前にやること

  • 冠の雪原で、狙うレジの部屋に入る（ジムバッジ8個が必要）
  • レジエレキ・レジドラゴは、どちらにするか選び終わっておく
  • インターネットは切っておく
スタート位置
光がついていない状態で、像の前に立つ
聞かれる数
  1. 狙うレジ：1回＝レジロック、2回＝レジアイス、3回＝レジスチル、4回＝レジエレキ、5回＝レジドラゴ、押さない＝前回と同じ
例：レジアイス → ①2回。スタートすると、白の点滅で選んだレジを教えてくれる
止め方
色違いが出ると、ゲームが手持ちの画面で止まる。1秒長押しでマクロを止めて、自分で捕まえる

レジの色違いは「ひかるおまもり」が効かず、平均で約50時間かかる。レジアイスは色の差が小さいので、ふつうの色のスクショを撮っておくと見比べやすい。

強いシンボル 無人厳選

ゲームを起動 → 出現場所でいきなり戦闘 →「にげる」→ ゲームを閉じる、をくり返す。

スタート前にやること

  • 狙う強いシンボルを一度消す（倒す・逃げる・捕まえるなど）。そのあと出現場所の真上に立つ
  • Y通信バグ（VSバグ）を有効にする → 本体の日付を1日進めて戻す → レポートを書く → ゲームを閉じる
  • 天気で出るシンボルは、狙う天気になる日付にしておく（捕まえる前に日付を戻す）
  • 使うユーザーを、ホームのいちばん左にしておく
スタート位置
ホーム画面で、剣盾のアイコンにカーソルを合わせた状態
聞かれる数
なし
止め方
色違いが出ると、ゲームが手持ちの画面で止まる。1秒長押しでマクロを止めて、自分で捕まえる

毎回、Y通信でインターネットにつなぐ動きが入る。「ひかるおまもり」があれば平均で約23時間。

タイミング調整

「にげる」を入力するタイミングを、0.1秒単位でずらして保存する。

聞かれる数
  1. どちらを直すか：1回＝レジ系、2回＝強いシンボル
  2. 遅らせる回数（1回＝0.1秒）
  3. 早める回数（1回＝0.1秒）
例：レジ系を0.3秒遅らせる → ①1回 ②3回 ③押さない ②と③をどちらも押さないと、初めの値に戻る
結果
今どれだけずらしているかを点滅で教えてくれる。白の回数＝遅らせた0.1秒の数、黄の回数＝早めた0.1秒の数、水色1回＝初めの値のまま

どっちに直す？

  • 白く光るのが早すぎる（戦闘メニューより前）→ 遅らせる
  • 白く光るのが遅すぎる（メニューから1.5秒より後）→ 早める

ちゃんと効くかの確かめ方：20回（2秒）早めると、ふつうのポケモンでも止まるはず。止まったのを確かめたら、20回遅らせて戻す。ずらした量は足し算されるので、10回ずつ2回に分けて入れてもいい。

機能ごとの説明：BDSP 色違い

しくみ

色違いが出ると、光る演出のぶん「たたかう」の表示が約2秒遅れる。マクロは「たたかう」が出てから2秒以内に十字キー上 →「にげる」を押すので、

  • ふつうのポケモン → 逃げて、また出現させる
  • 色違い → 上が間に合わず「たたかう」→ いちばん上の技（「いやしのねがい」など）で先頭が倒れ、次のポケモンを選ぶ画面で止まる

ゲームが止まっていたら、1秒長押しでマクロを止めて、自分で捕まえる。

最初に必ずタイミング調整（BDSP）をする。十字キー上を押す瞬間にLEDが白く光る。ふつうのポケモンが出たとき、「たたかう」が出てから2秒以内（1秒くらい後がちょうどいい）に白く光るように合わせる。なつき度が上がると演出が増えてずれるので、そのときはソフトリセットしてやり直す。

シェイミ 無人厳選

シェイミと戦闘 → 逃げる → 下に走ってマップを切り替える → 上に戻ってシェイミを復活させる、をくり返す。

スタート前にやること

  • 花の楽園に行くためのアイテム（オーキドのてがみ）を受け取っておく
スタート位置
「花の楽園」で、シェイミの前に立ってレポートを書いた状態
聞かれる数
なし

ダークライ 無人厳選

宿に入る → 新月島でダークライと戦闘 → 逃げる → 宿で目覚める → 宿を出る、をくり返す。

スタート前にやること

  • メンバーズカードを受け取っておく
  • ミオシティのクレセリアのイベントを終わらせておく
スタート位置
ミオシティのポケモンセンターの後ろにある「波止場の宿」の前に立って、レポートを書いた状態
聞かれる数
なし

アルセウス 無人厳選

てんかいのふえを吹く → 光の階段を上る → アルセウスと戦闘 → 逃げる → 階段を下りる、をくり返す。

スタート前にやること

  • てんかいのふえ（レジェンズアルセウスのクリア特典）を受け取っておく
  • ディアルガかパルキアを捕まえておく
  • アルセウスはLv80なので、先頭に「けむりだま」を持たせるのがおすすめ
スタート位置
テンガン山の頂上、槍の柱に入るところ（洞窟の出口）に立って、レポートを書いた状態
聞かれる数
なし

タイミング調整（BDSP）

十字キー上を押すタイミングを、0.1秒単位でずらして保存する。

聞かれる数
  1. どれを直すか：1回＝シェイミ、2回＝ダークライ、3回＝アルセウス
  2. 遅らせる回数（1回＝0.1秒）
  3. 早める回数（1回＝0.1秒）
例：ダークライを0.5秒早める → ①2回 ②押さない ③5回。押した分は、今までの調整に足される。 ②と③をどちらも押さないと、元の値に戻る
結果
今どれだけずらしているかを点滅で教えてくれる。白の回数＝遅らせた0.1秒の数、黄の回数＝早めた0.1秒の数、水色1回＝元の値のまま

どっちに直す？

  • 白く光るのが「たたかう」より前 → 遅らせる
  • 白く光るのが「たたかう」から2秒より後 → 早める

機能ごとの説明：FRLG 色違い

しくみ

色違いは登場するときに光るので、メッセージが出るまでが少し遅れる。この時間差を使って、

  • ふつうのポケモン →「にげる」を選んで逃げる
  • 色違い → 逃げずに戦闘画面のまま残る

戦闘画面のまま止まっていたら、1秒長押しでマクロを止めて、自分で捕まえる。色違いの確率は1/8192。

野生（あまいかおり）

「あまいかおり」でポケモンを出す → 色違いでなければ逃げる、をくり返す（1回 約27秒）。

スタート前にやること

  • あまいかおりを使うポケモンには、ほかのフィールド技（フラッシュ・いあいぎりなど）を覚えさせない
  • バッグの「どうぐ」「たいせつなもの」「ボール」に、それぞれ1種類以上入れておく
  • Xのメニューで「ポケモン」にカーソルを合わせて閉じる
スタート位置
くさむらの上や洞窟の中など、あまいかおりでポケモンが出るところ
聞かれる数
  1. あまいかおりのポケモンが、手持ちの何匹目か（押さない＝1匹目）
  2. 手持ちの数（押さない＝6匹）
例：手持ち6匹の3匹目が使う → ①3回 ②押さない

サンダー

サンダーに話しかけて逃げる → 外に出て戻ってサンダーを復活させる、をくり返す。

スタート前にやること

  • 先頭はすばやさ133以上・Lv36以上（リーフグリーンはLv35以上）
  • バッグの「どうぐ」のいちばん上にゴールドスプレーを置き、カーソルを合わせておく（まだ使わない）。1本で25回なので、150本以上がおすすめ
  • Xのメニューで「バッグ（どうぐ）」にカーソルを合わせて閉じる
スタート位置
むじんはつでんしょのいちばん奥、サンダーのすぐ左のマスで、右を向いて立つ
聞かれる数
  1. スプレーの種類：押さない＝ゴールド、1回＝シルバー、2回以上＝むしよけ
  2. 持っている本数の100の位
  3. 持っている本数の10の位
  4. 持っている本数の1の位
例：ゴールドスプレー150本 → ①押さない ②1回 ③5回 ④押さない 本数を全部押さないと999本として扱う。持っている本数がそれより少ないと途中でずれるので、本数は必ず入れる
終わり
スプレーを使い切ると止まる

フリーザー

サンダーと同じやり方で、フリーザーの色違いを探す。

スタート前にやること

  • 先頭はすばやさ117以上・Lv41以上
  • スプレーとXメニューの準備はサンダーと同じ（ただし1本で5回）
スタート位置
ふたごじま地下4階、フリーザーのすぐ右のマスで、左を向いて立つ
聞かれる数
  1. スプレーの種類：押さない＝ゴールド、1回＝シルバー、2回以上＝むしよけ
  2. 持っている本数の100の位
  3. 持っている本数の10の位
  4. 持っている本数の1の位
例：シルバースプレー40本 → ①1回 ②押さない ③4回 ④押さない

ふたごじまの中は処理が重く、まれに動きがずれる。長い時間放っておくときは、ときどき様子を見る。

ファイヤー

ファイヤーと戦って、色違いでなければ逃げる、をくり返す。

スタート前にやること

  • 先頭はすばやさ122以上
  • バッグの「どうぐ」のいちばん上にゴールドスプレーを1本以上置き、カーソルを合わせておく（なければ、戦闘中に使えない道具。ふしぎなアメなど）
  • 手持ちに「かいりき」を使えるポケモンを入れる
  • Xのメニューで「バッグ（どうぐ）」にカーソルを合わせて閉じる
スタート位置
ともしびやまの山頂、ファイヤーのすぐ下のマスで、上を向いて立つ
聞かれる数
なし

デオキシス

追いかけっこ → 戦闘 → 逃げる、をくり返す。1回ちょうど60秒なので、動かした分数＝回数。

スタート前にやること

  • 先頭はすばやさ115以上（デオキシスのすばやさは、ファイアレッドではアタックフォルムで114、リーフグリーンではディフェンスフォルムで74）
  • バッグの「どうぐ」のいちばん上にゴールドスプレーを1本以上置き、カーソルを合わせておく（なければ、戦闘中に使えない道具）
スタート位置
たんじょうのしまで、追いかけっこを始める前に上を向いて立つ（Aで追いかけっこが始まる状態）
聞かれる数
なし

まれに追いかけっこでデオキシスを通り抜けて、戦闘にならない回がある。次の回で元に戻る。
